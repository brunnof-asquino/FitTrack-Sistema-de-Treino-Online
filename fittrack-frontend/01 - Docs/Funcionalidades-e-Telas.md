# FitTrack - Mapeamento de Telas e Funcionalidades

Abaixo está o mapeamento completo das telas do aplicativo FitTrack e suas respectivas funcionalidades com base nos requisitos da plataforma.

| Tela (Arquivo Vue) | Funcionalidade(s) Associada(s) |
| :--- | :--- |
| **`LandingView.vue`** | Apresentação inicial da plataforma e visão geral das soluções oferecidas pelo FitTrack. |
| **`auth/LoginView.vue`** | Autenticação de usuários (login com credenciais). |
| **`auth/RegisterView.vue`** | Cadastro e criação de conta de novos usuários. |
| **`FeedAllView.vue`** | Exibição do Feed "Geral" contendo publicações e treinos de toda a comunidade. |
| **`FeedFollowView.vue`** | Exibição do Feed "Seguindo" com acompanhamento do progresso e atividades das pessoas seguidas. |
| **`SuggestionsFeedView.vue`** | Feed com sugestões de treinos personalizados com base no perfil do usuário. |
| **`UploadView.vue`** | Upload de vídeos ou fotos de progresso físico publicados pelos próprios usuários. |
| **`WorkoutDetailView.vue`** | Visualização de detalhes do treino, execução de vídeos, marcar treino como realizado, acompanhamento de progresso.
| **`EditWorkoutDetailView.vue`** | Edição de informações e detalhes de um treino existente. |
| **`LikedWorkoutsView.vue`** | Visualização de treinos curtidos. |
| **`MyWorkoutView.vue`** | Listagem, organização e acesso rápido aos treinos salvos, favoritados ou criados pelo usuário. |
| **`profile/MyProfileView.vue`** | Perfil do próprio usuário, com estatísticas de progresso, histórico de atividades e treinos concluídos. |
| **`profile/PublicProfileView.vue`** | Perfil público de outros usuários.
| **`SearchView.vue`** | Exploração, busca e filtragem de treinos organizados por categorias. |
| **`NotificationsView.vue`** | Central de notificações sobre curtidas, novos comentários e novos seguidores. |
| **`admin/AdminDashboardView.vue`** | Dashboard administrativo geral com estatísticas e métricas da plataforma. |
| **`admin/AdminUsersView.vue`** | Listagem e controle geral de usuários e gerenciamento de suas permissões. |
| **`admin/AdminWorkoutView.vue`** | Gerenciamento, listagem e controle de treinos cadastrados no sistema. |
| **`admin/AdminUploadWorkoutView.vue`** | Formuário para cadastro de novos treinos pelo administrador. |
| **`admin/AdminCategoryView.vue`** | Gerenciamento e listagem de categorias de treinos. |
| **`admin/AdminUploadCategoryView.vue`** | Cadastro de novas categorias de treinos pelo administrador. |
| **`NotFoundView.vue`** | Tela de erro 404 para captura de rotas inexistentes. |
